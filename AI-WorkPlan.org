** DONE [#A] <<Create capWebVd_csu>> — mirror of capDns_csu :ai:
CLOSED: [2026-07-21 Mon]
SCHEDULED: <2026-07-21 Mon>
Create =py3/bisos/webCap/capWebVd_csu.py= with four commands, mirroring
=capDns_csu.py=:
- =webVd_update=: call =wvdConfigFunc()= to get config string; write it (sudo) to
  =/etc/nginx/sites-available/<serverName>=. Does NOT enable or reload — that is
  =webVd_enable='s job.
- =webVd_enable=: create symlink =/etc/nginx/sites-enabled/<serverName>= →
  =../sites-available/<serverName>= (sudo); run =sudo nginx -t && sudo nginx -s reload=.
  Idempotent — skip symlink creation if already present.
- =webVd_disable=: remove the symlink from =sites-enabled/= (sudo); run
  =sudo nginx -s reload=. Leaves =sites-available/= untouched.
- =webVd_verify=: check that =sites-available/<serverName>= exists, symlink in
  =sites-enabled/= is present, and =nginx -t= passes.
- =webVd_resolve=: run =curl -s -o /dev/null -w "%{http_code}" http://<serverName>=
  to confirm the virtual host responds.
- =webVd_fqdnPing=: ping =serverName= once (reuse =capDns_fqdnPing= pattern).
Also add =examples_csu= as a plain =@cs.track def= (not =cs.Cmnd= class — lesson
learned from capDns).
----- AI Results: ------
Created =py3/bisos/webCap/capWebVd_csu.py= with all six commands + =examples_csu=:
- =webVd_update=: writes config via tempfile + =sudo cp= to =sites-available/=.
- =webVd_enable=: =sudo ln -s= (idempotent); =sudo nginx -t= then =sudo nginx -s reload=.
- =webVd_disable=: =sudo rm= symlink from =sites-enabled/=; =sudo nginx -s reload=.
  Leaves =sites-available/= untouched.
- =webVd_verify=: checks =sites-available/= exists + symlink present + =sudo nginx -t=.
- =webVd_resolve=: =curl -s -o /dev/null -w '%{http_code}'= against =http://<serverName>=.
- =webVd_fqdnPing=: =ping -c 1 <serverName>=; accepts optional fqdn arg (same pattern
  as =capDns_fqdnPing=).
- =examples_csu=: plain =@cs.track def= — not =cs.Cmnd= class (avoids perfName error).
